## Installation

```sh
npx skills add liyown/skills-registry#v0.3.3 --skill java-code-reviewer
```

Or install the full set:

```sh
npx skills add liyown/skills-registry#v0.3.3
```

## Highlights

- **release-readiness CI workflow** at
  `.github/workflows/release-readiness.yml`. Two jobs on every push
  and PR to `main`:
  1. `validate` — runs `./scripts/validate.sh` (smoke + examples
     + full structural validation).
  2. `release-dry-run` — runs `./scripts/release.sh --dry-run`
     and asserts no new tag exists at HEAD. A regression in the
     release flow cannot pass CI unnoticed.
- **`pr-diff-example.diff`** added to `node-code-reviewer`,
  `python-code-reviewer`, and `react-code-reviewer`. All five
  reviewers now ship the same example asset surface (whole-file
  bad/good, per-scenario bad/good, `review-output.md`, and
  `pr-diff-example.diff`).
- **README "Skills at a Glance"** routing tables — two tables
  (Reviewers, Workflows) that mirror the first clause of each
  skill's `description` field, so consumers can pick the right
  skill without parsing every frontmatter.
- **`goal-driven-development/SKILL.md` "Install Path"** section
  documents the default install location, what gets copied, and
  the combined install command for the peer reviewer skills.
