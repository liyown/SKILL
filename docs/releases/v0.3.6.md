## Highlights

- GitHub collaboration templates so the first contact a contributor
  has with the repo is structured:
  - `bug_report.md` — pre-flight points at `validate.sh`,
    `CONTRIBUTING.md`, and `docs/releases/INDEX.md`.
  - `feature_request.md` — pre-flight points at the Coverage
    Matrix and the "What Makes A Great Skill" section.
  - `config.yml` — disables blank issues and surfaces the
    release index, contributing guide, and the great-skill
    section as contact links.
  - `PULL_REQUEST_TEMPLATE.md` — 8-item self-check covering
    `validate.sh` exit, bad/good pairing, README sync, Coverage
    Matrix update, and `release.sh --dry-run` preview.
