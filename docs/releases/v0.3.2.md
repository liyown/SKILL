# v0.3.2

Released 2026-06-08. Source of truth: git tag `v0.3.2` (annotated).
This file mirrors the GitHub release notes at
<https://github.com/liyown/skills-registry/releases/tag/v0.3.2>.

## Installation

```sh
npx skills add liyown/skills-registry#v0.3.2 --skill react-code-reviewer
```

Or install the full set:

```sh
npx skills add liyown/skills-registry#v0.3.2
```

## Highlights

- **react-code-reviewer coverage gap closed.** Expanded from 4 to 10
  scenario prompts so the frontend reviewer is at parity with the
  backend reviewers:
  - `testing-reviewer.md` — Jest, Vitest, RTL, Playwright, Cypress;
    `act()` wrapping, mock scoping, behaviour-vs-implementation.
  - `forms-reviewer.md` — react-hook-form, Formik, Zod, server
    actions; submit disable, double-submit, schema-driven errors.
  - `state-reviewer.md` — Redux Toolkit, Zustand, Jotai, Context;
    selector memoisation, store splitting, SSR hydration.
  - `a11y-reviewer.md` — keyboard, screen reader, ARIA, focus
    management, contrast, live regions, reduced motion.
  - `error-boundary-reviewer.md` — top-level vs route-level
    boundaries, event-handler async errors, fallback UX, log
    forwarding.
  - `bundle-reviewer.md` — tree-shaking, dynamic imports, route-
    level code splitting, icon imports, barrel files.
- 6 paired `bad-*` / `good-*` example `.tsx` files for the new
  react scenarios (testing missing act, a11y missing label, forms
  double-submit, state store-recreate, error-boundary missing,
  lodash barrel import).
- "What Makes A Great Skill" section in `CONTRIBUTING.md`
  capturing the patterns used by `anthropics/skills` and
  `vercel-labs/agent-skills`.
- `docs/CHANGELOG.md` re-created with the cumulative v0.2.0 →
  v0.3.2 history.
- Reviewer Coverage Matrix in README expanded from 7 to 11 rows
  to host the new react scenarios.
