## Highlights

- `scripts/release.sh` extended with `--notes-from <file>` and
  `--no-publish` flags. The previous release flow wrote the GitHub
  release notes inline as `gh release create --notes "..."`, which
  broke on shell-globbed content (the literal `at` in some release
  notes was being treated as a glob pattern and failing to match).
  The new `--notes-from` flow validates the file exists, then
  surfaces the exact `gh release create --notes-file ...` command
  the caller should run after the tag is pushed. The script does
  not call `gh` itself; keeping the call-site explicit makes the
  auth state and CLI version visible.
